# casa-milano

Ricerca automatizzata di appartamenti per studenti universitari a Milano (3 inquilini, Bicocca + Politecnico Bovisa).

Le istruzioni operative per l'agente sono in [`CLAUDE.md`](./CLAUDE.md).

- Stato delle ricerche: [`analizzati.json`](./analizzati.json) — lista degli annunci già esaminati.
- Output: [`risultati.md`](./risultati.md) — appartamenti che rispettano tutti i criteri.

L'agente Cowork remoto gira ogni mattina e committa qui gli aggiornamenti.
